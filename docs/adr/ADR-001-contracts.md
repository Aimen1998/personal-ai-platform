# ADR-001: العقود المعمارية

**التاريخ:** 2026-09-04
**الحالة:** مقبول

## السياق
لا مشروع مفتوح واحد يغطي أكثر من ~55% من المتطلبات.
Hermes Agent يغطي المساعد الشخصي، ولا يغطي RAG على وثائقي
ولا الحوكمة ولا العزل متعدد المستأجرين.

## القرار
1. عقدان ثابتان: OpenAI-compatible للأعلى · MCP للجانب
2. Core يقف **بجانب** Hermes لا أمامه
3. **لا نبني agent loop أبدًا**

## البدائل المرفوضة
- **Core كـproxy أمام Hermes** — Hermes حلقة كاملة تريد أن تقود.
  وضعها خلف proxy يعني تعطيل نصفها أو بناء حلقة فوق حلقة.
- **بناء agent loop خاص** — إعادة اختراع 26,099 commit.
- **LangGraph / CrewAI** — أطر لبناء وكلاء لا وكلاء جاهزون.

## النتائج
- أسهل: استبدال الواجهة أو الوكيل بلا مساس بـcore
- أصعب: ازدواج ذاكرة بين SQLite في Hermes وPostgres عندي — يُقاس في Phase 6
